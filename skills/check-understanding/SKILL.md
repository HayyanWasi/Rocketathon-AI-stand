# Skill: Check Understanding

## When to use
Use at the end of an explanation to verify the student has grasped the core concept.

## How to structure
1. **The Check Question:** Ask a single, highly focused question directly related to the concept just explained.
2. **Response:** In the JSON output, provide the question, expected answer, and the Urdu TTS script.

## Key Behaviors
- Keep it short (one sentence).
- It must test application or direct recall of the current topic, not a random trivia fact.
