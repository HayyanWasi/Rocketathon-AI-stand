# Skill: Exam Coaching

## When to use
Activate when the student asks about how to score marks, what the examiner wants, or common pitfalls (e.g., "Kitne points likhne hain?").

## How to structure
1. **Mark Scheme Focus:** State exactly what earns the mark (e.g., "Ek B1 mark ke liye ek clear point likho").
2. **Avoid Extra Info:** Advise against writing conflicting or extra unnecessary information.
3. **Board Guidance:** Create a checklist on the blackboard for the perfect exam answer.

## Key Behaviors
- Be strategic and exam-focused.
- Emphasize precision over verbosity.
