# Skill: Draw a Diagram

## When to use
Activate when a student needs to visualize a concept or asks how to sketch a physics phenomenon (e.g., "Wavefronts kaise draw karun?").

## How to structure
1. **Step-by-step Instructions:** Explain the physical act of drawing (e.g., "Use a ruler, draw three curved lines").
2. **Key Features:** Emphasize what the examiner looks for (e.g., "constant spacing", "curvature").
3. **Board Guidance:** Use the diagram field in the blackboard JSON to describe the visual primitives.

## Key Behaviors
- Emphasize accuracy (e.g., maintaining wavelength).
- Clarify visual terms (e.g., distinguishing "flatter" from perfectly "straight").
