# Skill: Correct a Misconception

## When to use
Activate when the student's statement contradicts physics facts (e.g., "Wavelength increases after diffraction").

## How to structure
1. **Direct Correction:** Explicitly state what is wrong (e.g., "Nahi beta, wavelength same rehti hai").
2. **Correct Fact:** Provide the correct physics fact.
3. **Explanation:** Explain *why* the student's assumption was incorrect, using evidence.
4. **Board Guidance:** Show the contrast (e.g., "Incorrect vs Correct") on the blackboard.

## Key Behaviors
- Be caring but firm about the physics facts.
- Pinpoint the exact error rather than just re-explaining everything.
